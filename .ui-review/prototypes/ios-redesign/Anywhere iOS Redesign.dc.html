Anywhere iOS redesign · complete
iPhone 16 · 393 × 852 pt
Dark first, light twin to the right where listed. Icons are Lucide, the same set as the desktop app: 24-unit grid, 2 pt stroke (1.75 in the tab bar), round caps and joins, outline only, tinted with the text colour. Type is the system font (SF Pro on Apple devices). Network states: one strip per screen; Reconnecting and Reconnect failed dim last-known data and disable answers and writes. Screens with a pinned bottom action or composer (Chat, PR detail, Changes, Diff, Files, File preview) hide the tab bar. Inbox Approve/Deny, Chat Allow/Deny, toggles, segmented controls and the Merge method menu are clickable.
