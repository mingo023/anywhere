Mở finder từ:
Một finder, nhiều chỗ dùng. Add project, Browse lúc clone, đổi Worktrees folder đều mở cùng modal này; chỉ khác tiêu đề, nút chính và điều kiện bật nút.
Chỉ đọc. Dùng fs.list / fs.read / fs.search pocketd đã có; mỗi cột tải riêng nên có spinner ngắn khi host chậm.
Phím: ↑↓ chọn, → vào, ← ra, ↵ nút chính, ⌘F tìm, ⌘⇧. hiện file ẩn, esc đóng.
