Kịch bản:
Ô máy đứng đầu hàng. Chọn máy trước, rồi mới chọn project; menu project chỉ đưa lên các repo có trên máy đó.
Repo đi theo máy. Đổi máy thì giữ nguyên repo nếu máy kia cũng có (khớp theo GitHub remote), không thì hiện thẻ "Clone / Dùng folder có sẵn".
Clone chạy trên host, bằng git của host. Xong thì project hiện trong sidebar với nhãn host, và gửi được ngay.
