# Release and Updates Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use /implement to execute this plan task-by-task.

**Goal:**
- Release and Dev builds of Anywhere get separate identities (home, bundle id, daemon label, phone port), chosen at build time.
- The git tag version reaches pocketd's hello.ok.
- `scripts/release-mac.sh <version> [--publish]` builds, signs, notarizes and staples a universal `Anywhere.dmg` with pocketd inside as `AnywhereDaemon.app`, and with `--publish` puts it and a Sparkle `appcast.xml` on a GitHub release.
- The release app registers pocketd with `SMAppService`, updates itself through Sparkle without interrupting anything, and a `v*` tag publishes from GitHub Actions.

**Architecture:**
- The build env picks the channel:
  - Rust reads `ANYWHERE_CHANNEL` and `ANYWHERE_VERSION` through `option_env!` in a new `channel` crate.
  - Go reads `-X pocketd/internal/config.channel=release` and `-X main.version=…`.
  - Unset means Dev.
- Every hard-coded `.coding-pocket` and service label goes through these.
- The release script is POSIX sh with one function per stage (`build`, `assemble`, `sign`, `make_dmg`, `notarize`, `main`), so later PRs add the helper app, Sparkle and publishing in place.
- pocketd ships as `Contents/Library/Helpers/AnywhereDaemon.app` with a bundled LaunchAgent plist; the app registers it through `objc2-service-management` in the `daemon` model crate.
- The universal build links ghostty's prebuilt universal static lib and `lipo`s the per-target binaries.
- Sparkle is loaded at run time with `NSBundle` (`crates/pocket/src/updates.rs`), so dev builds and tests never need the framework. The appcast is generated by Sparkle's `generate_appcast` and uploaded next to the DMG.

**Toolset:**
- pocketd unit test: `cd packages/pocketd && go test ./internal/<pkg> -run '<TestName>' -count=1`
- pocketd all: `cd packages/pocketd && go vet ./... && go test -race -count=1 ./...`
- regenerate server goldens: `cd packages/pocketd && go test ./internal/proto -run TestServerGolden -update`
- regenerate the launchd plist golden: `cd packages/pocketd && go test ./internal/launchagent -run TestPlistMatchesGolden -update`
- protocol (TS): `pnpm --filter @pocket/protocol test`
- desktop: `cd packages/desktop && cargo test -p channel` / `cargo test -p daemon <name>`. Gates: `cargo build --workspace && cargo clippy --workspace --all-targets && cargo test --workspace`
- shell: `shellcheck scripts/release-mac.sh scripts/build-ghostty.sh scripts/bundle-dev.sh`
- x86_64 target (PR 4, once per machine): `rustup target add x86_64-apple-darwin`
- UI captures (repo root): `.ui-review/fixture/capture.sh <dir> <name>=<step>,<step>…`
- local release without notarizing: `ANYWHERE_SKIP_NOTARIZE=1 scripts/release-mac.sh 0.0.1`
- Full gate (repo root): `scripts/check.sh`. It uses a scratch `POCKET_HOME`. Never point tests at the live pocketd.

**Read first:**

- `docs/adr/0005-pocketd-upgrades-in-place.md`: why v0.1.0 waits for the hot-swap plan.
- `docs/adr/0003-desktop-code-layout.md`: where new desktop code goes.
- `CLAUDE.md` (repo root): desktop layout and test style.
- `packages/pocketd/internal/config/config.go`, `internal/launchagent/launchagent.go` and `cmd/pocketd/{serve,daemon}.go`: every place the home and label are used.

- `scripts/bundle-dev.sh`: the release `Info.plist` and `assemble` copy its layout.

## Why this approach

- **Build-time channel, not runtime.** A shipped app can't be talked into using the Dev home, and a dev build can't touch the installed app's service. `option_env!` is tracked by cargo, so changing `ANYWHERE_CHANNEL` rebuilds `channel` and everything that depends on it. Rejected: reading the bundle id at runtime, because unbundled `cargo run` has none.
- **Release keeps today's names** (`~/.coding-pocket`, `dev.mingo.anywhere.pocketd`, 4517) because the bundle id and label are permanent. Dev gets new ones. This costs the maintainer one migration.
- **pocketd version on the wire now.** It's cheap, and the hot-swap plan and the phone can show which pocketd they reached. No consumer yet.
- **The script is local first**, with secrets from env, so the same file later runs in CI unchanged (ADR 0004).
- **Universal via ghostty's own xcframework lib** rather than a zig build per arch: zero extra build time and one link path. Rejected: a per-arch `zig-out-<arch>` (two more zig builds, plus per-arch cgo flags).
- **Sparkle 2, not our own updater.** Strangers' machines hit cases Sparkle already handles (app in Downloads, no write access to /Applications, bad signature). Rejected: a Zed-style updater.
- **SMAppService helper bundle, not a LaunchAgent plist with an absolute path.** A moved or deleted app takes its daemon along, and privacy prompts say "Anywhere". Costs macOS 13.
- **GitHub Releases, `releases/latest/download/…` URLs.** Free for a public repo, and the landing page and `SUFeedURL` never change.
- **Non-goals here:** hot swap (its own plan, `docs/plans/2026-10-06-pocketd-hot-swap.md`, which must merge before v0.1.0 is published), beta channel, phone UI.

## Notes for the implementer

Decisions and gaps found while planning. Read the part for your PR.

### PR 1, 2, 4: identity, script, universal

Contract additions:

- **`config.DefaultPort()`**: 4517 for Release, 4518 for Dev. Both pocketds bind the phone port from `config.json`, so with one default the second pocketd to start would fail. A fresh Dev home gets 4518. The existing `~/.coding-pocket/config.json` keeps 4517.
- **No `config.DefaultHome()`.** The three call sites (`serve.go:186`, `daemon.go:71`, `daemon.go:108`) already hold `user` and become `filepath.Join(user, config.HomeName())`.
- **Rust identity lives in a new model crate, `crates/channel`** (`src/channel.rs`, no deps). `daemon` depends on it. `daemon::sock_path` is its only caller today; `bundle_id`, `daemon_label` and `version` are for PR 3/5/7.
- **hello.ok gains `version`** (`omitempty`), filled from a new `wsserver.Server.Version`. `serve.go` passes `versionString()`. There's a new golden `hello_ok_version.json`, and the TS schema gets `version?: string`. The desktop doesn't read it yet; the `status` op already has `Version`. A later PR that needs it adds `version` to `agents::Frame` and `Event::Connected`.
- **`release-mac.sh` interface for PR 3 and PR 5–7:**
  - Globals set by `main`: `ROOT DESKTOP TARGET OUT APP DMG VERSION SIGN_ID`.
  - `build` leaves `$OUT/pocket-desktop` and `$OUT/pocketd` (universal after PR 4).
  - `assemble` writes `$APP` from them.
  - `sign` signs `$APP` only, without `--deep`. PR 3 must sign `Contents/Library/Helpers/AnywhereDaemon.app` before signing the outer app.
  - `ANYWHERE_NOTARY_KEY` is a **path** to the `.p8` key, so CI writes the secret to a temp file.
  - `main` exports `MACOSX_DEPLOYMENT_TARGET=13.0`. The zig-built ghostty objects are already minos 13.0.
- **Dev bundle file is `Anywhere Dev.app`**, not only its CFBundleName. It also moves to LSMinimumSystemVersion 13.0.
- **`.ui-review/config.json` changes too.** Its `launch` pins `POCKET_HOME=~/.coding-pocket` and moves to `~/.coding-pocket-dev`.

Deviations:

- **PR 4 drops the per-arch zig builds.**
  - ghostty's existing `-Demit-lib-vt` build already writes a universal static lib to `zig-out/lib/ghostty-vt.xcframework/macos-arm64_x86_64/libghostty-vt.a`; `lipo` reports `x86_64 arm64`.
  - It needs `xcodebuild`. The plan passes `-Demit-xcframework=true` so a missing Xcode fails loudly.
  - `term/build.rs` and `vt.go` link that one file for every arch, so there's no `CARGO_CFG_TARGET_ARCH` switch and no per-arch cgo flags. The default `zig-out` include dir stays.
  - Verified on this Mac:
    - an rlib that bundles the fat lib links and runs on arm64;
    - `CGO_ENABLED=1 GOARCH=amd64 go build` against it links an x86_64 binary.
  - Not verified:
    - the x86_64 cargo build of gpui (needs `rustup target add x86_64-apple-darwin`);
    - running x86_64 binaries (this Mac has no Rosetta).
- **Only the DMG is stapled**, per the contract. The app inside is covered by the DMG's notarization, but its own ticket is checked online at first launch. Sparkle's update archive is the same stapled DMG (PR 6), so nothing else needs stapling.
- **One-time migration (maintainer, manual).**
  - The old dev-installed service `dev.mingo.anywhere.pocketd` must be booted out before the first `make pocketd` on PR 1, because that label now belongs to the release app. Booting it out closes its Terminals.
  - Dev starts fresh in `~/.coding-pocket-dev` (port 4518; the phone re-pairs with Dev).
  - `~/.coding-pocket` stays for the release app.

### PR 3: daemon in the bundle

Contract additions and deviations:

- **New Rust API, `daemon::service`** (`crates/daemon/src/service.rs`):
  - `enum Service { NotRegistered, Enabled, RequiresApproval, NotFound }`
  - `should_register(Service) -> bool`
  - `status() -> Service`
  - `register() -> Result<(), String>`
  - `register_if_needed()`
  - `open_login_items()`
- **`daemon` depends on `channel`.** The plist name is `format!("{}.plist", channel::daemon_label())`.
- **`terminals::link` changes.**
  - New `Hint { Install, LoginItems, Reopen }`.
  - `Link::hint` returns `Option<Hint>` instead of `bool`.
  - `Link` gains `pub(crate) service: Option<Service>`, which is set only in release builds.
  - `Reopen` is new. In release, with the service on but pocketd not answering, "pocketd daemon install" would be wrong advice.
  - In the `LoginItems` state, "Anywhere's background service is off." replaces "Starting Pocket's terminal service…" rather than sitting under it.
- **The status is read on "down", not when the hint timer fires.** It runs on the background executor. Reading it at 10s would let a render between the timer and the reply show the dev hint for a frame.
- **Templates are named for what they become.**
  - `packages/desktop/assets/AnywhereDaemon-Info.plist.in` takes `@VERSION@`.
  - `packages/desktop/assets/dev.mingo.anywhere.pocketd.plist` has nothing to substitute, so the script copies it as-is.
  - Both hard-code release IDs, since only the release script uses them.
- **Two codesign calls, not three.** Signing `AnywhereDaemon.app` signs its main executable `pocketd` with the same options, so a separate binary pass would be overwritten. The order is still inner-first: helper bundle, then outer app.
- **Script variables from PR 2:** `$ROOT`, `$OUT`, `$APP`, plus:
  - `$VERSION` holds the value written to the outer `CFBundleShortVersionString`/`CFBundleVersion`.
  - `$SIGN_ID` holds the codesign identity (resolved in `main`).
  - `ANYWHERE_SKIP_NOTARIZE=1` makes `notarize` return early for a local run.
- **The `daemon install` refusal is path-based, not `config.Release()`.** It refuses any exe under `*.app/Contents/`. That is the condition that makes it wrong (SMAppService owns it), and a dev build copied into a bundle is caught too.
- **No StandardOutPath/StandardErrorPath in the bundled plist.** It can't expand `~`. Instead, `serve` calls `debug.SetCrashOutput` to `<home>/logs/launchd.log` when `XPC_SERVICE_NAME == config.Label()` and `config.Release()`. Ordinary logs already go to `pocketd.log` via `logfile`.
- **Depends on PR 1 replacing `launchagent.Label` with `config.Label()`** (`serve.go:67`).
- **Migration.** A maintainer machine with a pre-PR-1 `pocketd daemon install` has `~/Library/LaunchAgents/dev.mingo.anywhere.pocketd.plist`, which uses the release label. Task 1.7 boots it out and Task 3.7 checks it is gone. Nothing has been published, so no user has one.

**Deviations from ADR 0004**
- **No `build.rs` and no link-time Sparkle.** The app loads `Contents/Frameworks/Sparkle.framework` at run time with `NSBundle` and looks up `SPUStandardUpdaterController` with `AnyClass::get`. `cargo run`, `cargo test`, capture mode and dev bundles then never need the framework, and there is no weak-link or rpath setup to get wrong. This is the same bundle-or-nothing check that `channel::is_release()` gates.
- **`SUPublicEDKey` is a constant in `release-mac.sh`**, not `ANYWHERE_SPARKLE_PUBLIC_KEY`. It is public, it must never change, and a constant leaves CI one fewer value to set. `generate_keys` therefore moves to PR 5, Task 5.1.
- **Sparkle's `XPCServices` are deleted** from the bundled framework. Sparkle's sandboxing guide says a non-sandboxed app doesn't need them ("Removing the XPC Services"). That leaves three signing steps: `Autoupdate`, `Updater.app`, the framework.
- **"Restart to update" is a card above the sidebar footer** (`sidebar/update.rs`, next to `usage.rs`) rather than a replacement for the footer. "Add project" and Settings stay where they are.
- **`seen_version` is recorded at launch**, so "What's new" shows for one session or until dismissed, and a first install never shows it.

**Unverified (check during execution)**
- **`define_class!` with a `&block2::Block<dyn Fn()>` argument and a `Bool` return** for `updater:willInstallUpdateOnQuit:immediateInstallationBlock:`. No protocol is declared, so objc2 checks no encoding. Sparkle calls the method because `respondsToSelector:` is true.
- **Calling Sparkle's install block from a foreground task.** It must run outside an entity update. Sparkle ends with `[NSApp terminate:]`, and gpui-pre-macos `platform.rs:557-575` shows that terminating while app state is borrowed double-borrows. Install-on-quit works because GPUI quits through `[NSApp terminate:]` (same file).
- **`cx.set_menus` replaces GPUI's empty default menu bar.** cmd-Q must still quit, and cmd-C/V in terminals and inputs must still work, since those come from key bindings, not menus.
- **`generate_appcast` keeps earlier items from the downloaded `appcast.xml`** when their archives aren't in the folder. Only the newest item matters for updating, so this is cosmetic.
- **`gh release create` with assets publishes only after the uploads finish.** If not, `/releases/latest/download/appcast.xml` could 404 for a few seconds.
- **Pre-release tags such as `0.2.0-beta.1` as `CFBundleVersion`.** Apple documents `CFBundleVersion` as up to three integers. Notarization is expected to accept it, but Sparkle never sees pre-releases (they stay out of the appcast). If notarization rejects it, `assemble` must map pre-release versions for `CFBundleVersion`.
- **The macos-15 runner image ships `rustup`.** It does today.

```sh
#!/bin/sh
# Builds a signed, notarized and stapled Anywhere.dmg in packages/desktop/target/release-mac (ADR 0004).
# Usage: scripts/release-mac.sh <version>    e.g. 0.1.0
# Signs with ANYWHERE_SIGN_ID, default the keychain's first "Developer ID Application" identity.
# Notarizes with the notarytool keychain profile ANYWHERE_NOTARY_PROFILE (default "anywhere"),
# or, when ANYWHERE_NOTARY_KEY (path to a .p8) is set, with that App Store Connect API key,
# ANYWHERE_NOTARY_KEY_ID and ANYWHERE_NOTARY_ISSUER.
# ANYWHERE_SKIP_NOTARIZE=1 skips notarizing for a local check of the bundle.
set -eu
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
DESKTOP="$ROOT/packages/desktop"
TARGET="${CARGO_TARGET_DIR:-$DESKTOP/target}"
OUT="$DESKTOP/target/release-mac"
APP="$OUT/Anywhere.app"
DMG="$OUT/Anywhere.dmg"

fail() {
  echo "release-mac: $*" >&2
  exit 1
}

build() {
  "$ROOT/scripts/build-ghostty.sh"
  (cd "$DESKTOP" && ANYWHERE_CHANNEL=release ANYWHERE_VERSION="$VERSION" cargo build --release -p pocket --target aarch64-apple-darwin)
  cp "$TARGET/aarch64-apple-darwin/release/pocket-desktop" "$OUT/pocket-desktop"
  (cd "$ROOT/packages/pocketd" && CGO_ENABLED=1 GOARCH=arm64 go build -trimpath \
    -ldflags "-X main.version=$VERSION -X pocketd/internal/config.channel=release" -o "$OUT/pocketd" ./cmd/pocketd)
}

assemble() {
  mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
  cp "$OUT/pocket-desktop" "$APP/Contents/MacOS/pocket-desktop"
  cp "$DESKTOP/assets/AppIcon.icns" "$APP/Contents/Resources/AppIcon.icns"
  cat > "$APP/Contents/Info.plist" <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>CFBundleIdentifier</key><string>dev.mingo.anywhere</string>
  <key>CFBundleName</key><string>Anywhere</string>
  <key>CFBundleExecutable</key><string>pocket-desktop</string>
  <key>CFBundleIconFile</key><string>AppIcon</string>
  <key>CFBundlePackageType</key><string>APPL</string>
  <key>CFBundleShortVersionString</key><string>$VERSION</string>
  <key>CFBundleVersion</key><string>$VERSION</string>
  <key>NSHighResolutionCapable</key><true/>
  <key>LSMinimumSystemVersion</key><string>13.0</string>
</dict>
</plist>
PLIST
  plutil -lint "$APP/Contents/Info.plist"
}

sign() {
  codesign --force --timestamp --options runtime \
    --entitlements "$DESKTOP/assets/Anywhere.entitlements" --sign "$SIGN_ID" "$APP"
  codesign --verify --deep --strict --verbose=2 "$APP"
}

make_dmg() {
  stage="$OUT/dmg"
  mkdir -p "$stage"
  ditto "$APP" "$stage/Anywhere.app"
  ln -s /Applications "$stage/Applications"
  hdiutil create -volname Anywhere -srcfolder "$stage" -format UDZO -ov "$DMG"
  rm -rf "$stage"
  codesign --force --timestamp --sign "$SIGN_ID" "$DMG"
}

notarize() {
  if [ "${ANYWHERE_SKIP_NOTARIZE:-}" = 1 ]; then return; fi
  if [ -n "${ANYWHERE_NOTARY_KEY:-}" ]; then
    set -- --key "$ANYWHERE_NOTARY_KEY" --key-id "$ANYWHERE_NOTARY_KEY_ID" --issuer "$ANYWHERE_NOTARY_ISSUER"
  else
    set -- --keychain-profile "${ANYWHERE_NOTARY_PROFILE:-anywhere}"
  fi
  xcrun notarytool submit "$DMG" "$@" --wait
  # A rejected submission leaves no ticket, so stapling fails; `xcrun notarytool log <id>` says why.
  xcrun stapler staple "$DMG"
  spctl -a -vvv -t install "$DMG"
}

main() {
  case "${1:-}" in
    [0-9]*.[0-9]*.[0-9]*) VERSION=$1 ;;
    *) echo "usage: scripts/release-mac.sh <version>, e.g. 0.1.0" >&2; exit 2 ;;
  esac
  SIGN_ID="${ANYWHERE_SIGN_ID:-$(security find-identity -v -p codesigning | awk '/"Developer ID Application/ { print $2; exit }')}"
  [ -n "$SIGN_ID" ] || fail "no Developer ID Application identity in the keychain; set ANYWHERE_SIGN_ID"
  # Matches LSMinimumSystemVersion; rustc, cc and cgo all read it.
  export MACOSX_DEPLOYMENT_TARGET=13.0
  rm -rf "$OUT"
  mkdir -p "$OUT"
  build
  assemble
  sign
  make_dmg
  notarize
  echo "release-mac: $DMG"
}

main "$@"
```

```rust
//! pocketd as a Login Item: the release app registers the LaunchAgent plist it ships.

/// What macOS reports for the bundled agent (`SMAppServiceStatus`).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Service {
    NotRegistered,
    Enabled,
    /// The user switched it off in Login Items.
    RequiresApproval,
    NotFound,
}

impl Service {
    fn from_raw(raw: isize) -> Self {
        match raw {
            1 => Self::Enabled,
            2 => Self::RequiresApproval,
            3 => Self::NotFound,
            _ => Self::NotRegistered,
        }
    }
}

/// An agent that never registered reports NotFound as often as NotRegistered.
pub fn should_register(s: Service) -> bool {
    matches!(s, Service::NotRegistered | Service::NotFound)
}

fn plist() -> String {
    format!("{}.plist", channel::daemon_label())
}

#[cfg(target_os = "macos")]
fn agent() -> objc2::rc::Retained<objc2_service_management::SMAppService> {
    let name = objc2_foundation::NSString::from_str(&plist());
    unsafe { objc2_service_management::SMAppService::agentServiceWithPlistName(&name) }
}

/// Blocks on launchd; keep it off the UI thread.
#[cfg(target_os = "macos")]
pub fn status() -> Service {
    Service::from_raw(unsafe { agent().status() }.0)
}

#[cfg(not(target_os = "macos"))]
pub fn status() -> Service {
    Service::NotFound
}

/// Blocks on launchd; keep it off the UI thread.
#[cfg(target_os = "macos")]
pub fn register() -> Result<(), String> {
    unsafe { agent().registerAndReturnError() }.map_err(|e| e.localizedDescription().to_string())
}

#[cfg(not(target_os = "macos"))]
pub fn register() -> Result<(), String> {
    Err(format!("{} needs macOS", plist()))
}

pub fn register_if_needed() {
    if should_register(status())
        && let Err(e) = register()
    {
        eprintln!("pocketd service: {e}");
    }
}

#[cfg(target_os = "macos")]
pub fn open_login_items() {
    unsafe { objc2_service_management::SMAppService::openSystemSettingsLoginItems() }
}

#[cfg(not(target_os = "macos"))]
pub fn open_login_items() {}
```

```rust
use daemon::service::Service;
use std::time::{Duration, Instant};

pub(crate) const HINT_AFTER: Duration = Duration::from_secs(10);

/// What the page tells the user once pocketd has been gone a while.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum Hint {
    /// No bundled service (dev build): install one by hand.
    Install,
    /// The user switched Anywhere off in Login Items.
    LoginItems,
    /// The bundled service is on, yet pocketd isn't answering.
    Reopen,
}

/// Whether the connection to pocketd is up, and since when it isn't.
#[derive(Default)]
pub(crate) struct Link {
    down_since: Option<Instant>,
    /// The bundled service's state; only release builds read it.
    pub(crate) service: Option<Service>,
}

impl Link {
    pub(crate) fn down(&mut self, now: Instant) {
        self.down_since.get_or_insert(now);
    }

    pub(crate) fn up(&mut self) {
        self.down_since = None;
    }

    pub(crate) fn is_down(&self) -> bool {
        self.down_since.is_some()
    }

    pub(crate) fn hint(&self, now: Instant) -> Option<Hint> {
        self.down_since.filter(|t| now.duration_since(*t) >= HINT_AFTER)?;
        Some(match self.service {
            None => Hint::Install,
            Some(Service::RequiresApproval) => Hint::LoginItems,
            Some(_) => Hint::Reopen,
        })
    }
}
```

```rust
//! Sparkle, loaded at run time from the app's Frameworks so dev builds, tests and captures never need it.
use super::Event;
use block2::{Block, RcBlock};
use futures::channel::mpsc::UnboundedSender;
use objc2::rc::{Allocated, Retained};
use objc2::runtime::{AnyClass, AnyObject, Bool, NSObject, NSObjectProtocol};
use objc2::{DefinedClass, MainThreadMarker, MainThreadOnly, define_class, msg_send};
use objc2_foundation::{NSBundle, NSString};
use std::cell::RefCell;

pub struct Ivars {
    tx: UnboundedSender<Event>,
    install: RefCell<Option<RcBlock<dyn Fn()>>>,
}

define_class!(
    // SAFETY: NSObject has no subclassing requirements, and Delegate doesn't implement Drop.
    #[unsafe(super(NSObject))]
    #[thread_kind = MainThreadOnly]
    #[name = "PocketUpdaterDelegate"]
    #[ivars = Ivars]
    struct Delegate;

    unsafe impl NSObjectProtocol for Delegate {}

    impl Delegate {
        /// The update is downloaded and verified. Keeping the block lets "Restart to update" install it now; Sparkle installs it at quit anyway.
        #[unsafe(method(updater:willInstallUpdateOnQuit:immediateInstallationBlock:))]
        fn will_install_on_quit(&self, _updater: &AnyObject, item: &AnyObject, install: &Block<dyn Fn()>) -> Bool {
            // SAFETY: SUAppcastItem.displayVersionString is a non-null NSString.
            let version: Retained<NSString> = unsafe { msg_send![item, displayVersionString] };
            *self.ivars().install.borrow_mut() = Some(install.copy());
            let _ = self.ivars().tx.unbounded_send(Event::Ready(version.to_string()));
            Bool::YES
        }
    }
);

/// The running SPUStandardUpdaterController. Sparkle holds its delegate weakly, so this keeps it alive.
pub struct Sparkle {
    controller: Retained<AnyObject>,
    delegate: Retained<Delegate>,
}

impl Sparkle {
    /// `None` when the app carries no Sparkle.framework, or off the main thread.
    pub fn start(tx: UnboundedSender<Event>) -> Option<Self> {
        let mtm = MainThreadMarker::new()?;
        let frameworks = NSBundle::mainBundle().privateFrameworksPath()?;
        let bundle = NSBundle::bundleWithPath(&NSString::from_str(&format!("{frameworks}/Sparkle.framework")))?;
        // SAFETY: the framework is the one release-mac.sh bundled and signed; loading it runs only its own initialisers.
        if !unsafe { bundle.load() } {
            return None;
        }
        let class = AnyClass::get(c"SPUStandardUpdaterController")?;
        let delegate = Delegate::alloc(mtm).set_ivars(Ivars { tx, install: RefCell::default() });
        // SAFETY: NSObject's init on a freshly allocated subclass.
        let delegate: Retained<Delegate> = unsafe { msg_send![super(delegate), init] };
        // SAFETY: matches -initWithStartingUpdater:updaterDelegate:userDriverDelegate: (SPUStandardUpdaterController.h:97).
        let controller: Allocated<AnyObject> = unsafe { msg_send![class, alloc] };
        let controller: Retained<AnyObject> = unsafe {
            msg_send![controller, initWithStartingUpdater: Bool::YES, updaterDelegate: &*delegate, userDriverDelegate: None::<&AnyObject>]
        };
        Some(Self { controller, delegate })
    }

    pub fn check(&self) {
        // SAFETY: -checkForUpdates: takes a nullable sender.
        let _: () = unsafe { msg_send![&*self.controller, checkForUpdates: None::<&AnyObject>] };
    }

    /// Installs the ready update and relaunches; `None` until one is ready.
    pub fn installer(&self) -> Option<Box<dyn FnOnce()>> {
        let install = self.delegate.ivars().install.borrow().clone()?;
        Some(Box::new(move || install.call(())))
    }
}
```

Functions:
```sh
# A published build is exactly the tagged commit.
check_tag() {
  tag="v$VERSION"
  if [ "$(git -C "$ROOT" rev-parse -q --verify "$tag^{commit}")" != "$(git -C "$ROOT" rev-parse HEAD)" ]; then
    echo "release-mac: tag $tag must exist and point at HEAD" >&2
    exit 1
  fi
  if [ -n "$(git -C "$ROOT" status --porcelain --untracked-files=no)" ]; then
    echo "release-mac: commit or stash changes before publishing" >&2
    exit 1
  fi
}

# The DMG goes up as a GitHub release; a stable one is also added to the appcast every installed copy polls.
# Sparkle signs the stapled DMG, so this runs after notarize.
publish() {
  tag="v$VERSION"
  case "$VERSION" in
    *-*)
      gh release create "$tag" "$DMG" --repo "$REPO" --verify-tag --prerelease --title "Anywhere $VERSION" --notes-file "$OUT/Anywhere.md"
      return
      ;;
  esac
  feed="$OUT/feed"
  rm -rf "$feed"
  mkdir -p "$feed"
  # generate_appcast adds to the items already in the folder's appcast, so start from the live one, if a stable release came before.
  if git -C "$ROOT" tag -l 'v*' | grep -v -- - | grep -vqx "$tag"; then
    gh release download --repo "$REPO" --pattern appcast.xml --dir "$feed"
  fi
  cp "$DMG" "$feed/Anywhere.dmg"
  cp "$OUT/Anywhere.md" "$feed/Anywhere.md"
  set -- --download-url-prefix "https://github.com/$REPO/releases/download/$tag/" --embed-release-notes --maximum-deltas 0 --link "https://github.com/$REPO/releases"
  # CI passes the private key in the environment; on the maintainer's Mac it's in the login Keychain.
  if [ -n "${ANYWHERE_SPARKLE_KEY:-}" ]; then
    printf '%s' "$ANYWHERE_SPARKLE_KEY" | "$ROOT/third_party/sparkle/bin/generate_appcast" --ed-key-file - "$@" "$feed"
  else
    "$ROOT/third_party/sparkle/bin/generate_appcast" "$@" "$feed"
  fi
  gh release create "$tag" "$DMG" "$feed/appcast.xml" --repo "$REPO" --verify-tag --latest --title "Anywhere $VERSION" --notes-file "$OUT/Anywhere.md"
}
```
