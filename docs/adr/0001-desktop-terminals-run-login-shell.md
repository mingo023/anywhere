# Desktop terminals run the user's login shell, and agents start inside it

Every terminal the desktop opens runs the login shell from the macOS user record, not `$SHELL`, which follows whoever launched the app. It starts from a clean Terminal.app-like env. Agents run as `<shell> -l -c '<agent …>; exec <shell> -l'`, not as the PTY's own process. This is on purpose, although the agent-sessions design spawns agents plainly. It lets the agent pick up the user's shell config, and it leaves the user at their prompt once the agent exits, as in any terminal. The cost is that a crashed Pocket-spawned agent no longer ends its terminal non-zero, so it no longer shows red; the crash stays in the scrollback. `pocketd run` still runs its command directly, because the user's own shell already wraps it.
