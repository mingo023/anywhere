# Sessions are agents; terminals belong to worktrees

A session is one agent process, not a terminal and its tabs, which reverses ticket 05 of `docs/wayfinder/agent-sessions`. Terminals, and their tabs and splits, belong to the worktree they were opened in, and a session card only points at its agent's pane. We chose this because the sidebar already groups work by project and worktree, so grouping by terminal again duplicated it: New session no longer picks a branch, and runs in the selected worktree. Selecting a project selects its main worktree, so the list, the main area and New session always share one worktree; the cross-worktree view is the rail and worktree roll-ups and the inbox. The costs: agentless terminals are no longer in the list and are reached through the worktree's tabs; pocketd must keep exited agents until their terminal closes instead of dropping them; a session stays in the worktree its terminal was opened in even if the agent `cd`s to another one, so that worktree's Changes miss those edits.
