Tutorial

Run your first agent in Anywhere

In this tutorial, we install Anywhere on a Mac, start Claude Code on one of your git repositories, watch it work, and review and commit the change it makes.

You need a Mac with macOS 13 or later and a git repository on it. On Linux or Windows, follow Install Anywhere for the first step, then continue here.

Install Anywhere

  1. Download Anywhere.dmg.
  2. Open the file and drag Anywhere to Applications.

Don't open Anywhere yet. We install an agent first, so Anywhere finds it on first launch.

Install Claude Code and sign in

Anywhere runs the agent command line tools that it finds on your Mac. We use Claude Code in this tutorial. If Claude Code is already installed and signed in, open Anywhere and go to the next step.

  1. Install Claude Code with the instructions on the Claude Code page.
  2. In Terminal, sign in: 
    claude auth login
  3. Open Anywhere from Applications.

The Anywhere window opens with the sidebar on the left. On first launch, the app registers its background service, pocketd, as a login item. pocketd runs the agents, so they keep working after you close the window.

To confirm that Anywhere found Claude Code, open Settings with ⌘, and select Agents. Claude Code is in the Providers list. If you see Claude Code not found instead, check that claude runs in a new Terminal window, then restart Anywhere.

To use another agent, see Supported agents.

Add a project

  1. In the sidebar, click the folder button at the top of the projects list.
  2. Click Add project….
  3. Select the folder of your git repository and confirm.

The project now shows in the sidebar.

Start a session

  1. Press ⌘N. The new session page opens and asks What should we build next?
  2. Check that the project chip shows your project and that the agent is Claude Code.
  3. Type a small, safe request. For example: 
    Add a short section to README.md that explains how to run the tests.
  4. Press Return.

The session opens as a chat, and Claude Code starts on the request. It works in your project's own checkout, on your current branch. To give an agent its own branch instead, see Start an agent in a new worktree.

Watch its status

The session's row in the sidebar shows its status. While Claude Code runs a turn, the row shows a spinner. That status is Working.

If Claude Code asks for permission, for example to run a command, the status changes to Needs you. The row shows an amber dot, and the session goes into the Inbox. Answer in the chat to let it continue.

Now switch to another app and wait for the turn to end. When it ends, Anywhere shows a banner, and the row shows a green dot and its title in bold. That status is Done. It means that a turn ended and nobody has seen it yet. If you watch the chat while the turn ends, the session goes straight to Idle instead.

Click the bell at the top of the sidebar to open the Inbox. It lists the sessions that need you, and the Done and Failed ones you haven't seen. For every status and where it shows, see Sessions and status.

Review its changes

  1. On the right edge of the window, click the branch icon to open Changes. The icon shows the number of changed files.
  2. Under Changes, click README.md. Its diff opens.
  3. Read the diff. If you want a different result, ask Claude Code for changes in the chat.
  4. In the commit box, type a message, such as Explain how to run the tests.
  5. Click Commit All, or press ⌘↩. With nothing staged, Anywhere commits every changed file.

The file leaves the list, and the panel shows No changes. You have run an agent, followed its status, and committed its work.
