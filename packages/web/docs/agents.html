Supported agents

Anywhere runs ten coding agents. It doesn't include any of them: it runs the agent command line tools it finds on your login PATH.

If Anywhere doesn't find an agent, Settings › Agents says <Agent> not found, followed by its install command. If the agent is already installed, restart Anywhere.

Settings › Accounts can hold more than one account each for Claude Code and Codex, and shows their usage.

Chat, terminal, and status

Every agent runs as a chat or in a terminal. In a chat, pocketd drives the agent through the protocol in the last column. Whether the agent reports its status from a terminal decides whether it is attached there.

Where an agent reports its status, it shows all five: Needs you, Failed, Done, Working, and Idle. In a terminal, an agent that doesn't report its status shows only terminal activity. The <agent> id is the value for --provider in the anywhere command.

The new session page starts Claude Code and Codex as a chat when Settings › Agents › Start as a chat is on, and in a terminal when it is off. It always starts the other agents as a chat. Every agent can run in a terminal from a tab's + menu.

Access and delegation

  • Pi and omp never ask before they use a tool, so their sessions always run with Full access.
  • Codex doesn't start in plan mode. The other agents can.
  • Claude Code and Codex chats can delegate work to other sessions. Cursor, Grok Build, OpenCode, fx, Hermes Agent, and Antigravity chats can when the agent supports MCP servers over HTTP. Pi and omp can't.

Agent settings

Settings › Agents lists each agent under Providers. Click an agent to open its page:

  • Enabled: whether the agent shows in the default agent choice, the new session page, automations, and AI commit messages.
  • Set as default: makes it the agent new sessions start with.
  • Defaults: the label, model, and effort a new session starts with.
  • Launch: the command Anywhere runs and the arguments it adds to send a prompt, resume, and fork.

pocketd also takes the command as a setting: pocketd config set <agent>.command <command>.
