How-to guide

Schedule an automation

An automation is a prompt that pocketd starts in an agent on a schedule: on chosen weekdays at a time, or every few minutes. Each run is an ordinary session, and runs keep firing while the desktop app is closed.

To open Automations, click Automations in the sidebar, or press ⌘⇧A.

Create an automation

  1. Click the + in the list header, or New automation on the empty page.
  2. Type a name. If you leave it empty, the name is the start of the prompt.
  3. Under Trigger, click Add trigger and choose Schedule. Then pick one:
    • Days and time: select the days, or a preset such as Weekdays, and enter a Time in 24-hour HH:MM.
    • Repeat: enter a number of minutes, or pick a preset such as 1 hour. The interval is from 5 minutes to 7 days.
  4. Under Instructions, write the prompt.
  5. Pick the agent, and the access mode on the access chip.
  6. Pick the project. Choose Worktree to start each run on a new branch off the branch you pick, or Local to run in the project's checkout.
  7. Click Create.

The automation's page shows its trigger, folder, agent, and Next run. To try it now, click Run now.

New automations use Edits access by default. To change the default, go to Settings › Automations › Permission mode. With Ask, a run pauses until you approve its actions from the Mac or the phone.

Pause, edit, or delete an automation

On the automation's page:

  • To stop it from firing, switch Active to Paused.
  • To change it, click Edit, make the changes, and click Save.
  • To delete it, open the ⋯ menu and click Delete.

Answer a run that needs you

A run whose agent asks for a permission or an answer has the status Needs you, like any other session. It waits until you answer.

  • The Automations list shows a banner with the automation's name and Answer.
  • The automation's page says that the automation is paused until you answer.
  • The run's page shows the request, with Allow once, Deny, and Reply in session.

Click Answer to open the run's session and reply there. An automation has one active run at a time, so the next scheduled run is skipped while this one waits.

Read past runs

The automation's page lists its Recent runs. Click All runs for the rest. Each run shows one of these statuses:

StatusMeaning
WorkingThe run's agent is running a turn.
Needs youThe run waits for your answer.
DoneThe run ended.
FailedThe run ended with an error.
StoppedThe run's session closed before the run ended.
SkippedThe run never started: the Mac was asleep past the grace window, or the last run was still working.

Settings › Automations › Keep run history sets how many runs to keep. The default is 50.

Choose what happens to missed runs

pocketd fires runs only while it is running and the machine is awake. A run that comes due while the Mac sleeps starts when it wakes, if it is late by less than the grace window. Otherwise the run is skipped. The grace window is 12 hours by default.

To change it, go to Settings › Automations and set Run late if missed by less than. To turn late runs off, turn off Catch up after sleep.
