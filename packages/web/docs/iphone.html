How-to guide

Pair an iPhone Coming soon

The Anywhere iPhone app shows your sessions, lets you answer agents that need you, and sends push notifications. It connects straight to the Mac over Tailscale.

Coming soonThe iPhone app isn't publicly available yet. This page describes how pairing works so you are ready when it is.

Before you start

  • Tailscale runs on the Mac and on the iPhone, signed in to the same tailnet. pocketd refuses to pair without it.
  • In Settings › Phone & Remote, Reachable from is set to Tailnet, the default. The Tailscale row shows Connected and the Mac's Tailscale address. If it doesn't, click Set up Tailscale.

Pair the phone

  1. On the Mac, open Settings with ⌘, and select Phone & Remote.
  2. Click Pair a phone. The Pair phone dialog shows a QR code and a code. Both expire after 5 minutes.
  3. On the iPhone, open the Anywhere app and tap Scan pairing code. Point the camera at the QR code.
  4. Confirm the pairing on the iPhone.

The Mac's dialog says Paired and closes. The phone shows in the Paired phones list.

Enter the code instead

  1. On the iPhone, tap Enter code instead.
  2. In Mac address, enter the Mac's Tailscale address, such as 100.101.102.103. If you leave out the port, the app adds 4517.
  3. In Code, enter the code that the Mac shows under the QR code.

Five wrong codes in a row lock pairing for one minute.

Pair from a terminal

On the Mac, pocketd pair prints the same QR code, the address, and the code.

Get push notifications

The iPhone can get a notification when a session needs you, fails, or is done, and when an automation run ends. Turn each kind on or off in the app's notification settings.

Notifications go from pocketd through the Anywhere push relay at https://push.getanywhere.dev to Apple. pocketd encrypts each alert so only your phone can read it. The relay stores no device tokens: the phone gives pocketd a sealed handle that only the relay can open. Live Activity updates are the exception: they pass through Apple unencrypted.

To send pocketd's pushes through a relay you run yourself, see The push relay.

Remove a phone

  1. On the Mac, open Settings › Phone & Remote.
  2. Under Paired phones, click Revoke on the phone's row.

The phone disconnects at once and has to pair again.

Change the port

pocketd listens for phones on port 4517. Change it only if another app already uses 4517. In Settings › Phone & Remote, click Show advanced settings and set Port to a number from 1024 to 65535.
