How-to guide

Run agents on another machine over SSH

Add a Mac, Linux, or Windows machine as a host, and Anywhere installs pocketd on it over SSH. Projects on the host show in your sidebar, and their agents run on the host.

Before you start

  • You can sign in to the machine with ssh from this computer, with your keys, your ~/.ssh/config, a key file, or a password.
  • The machine runs macOS, Linux, or Windows, on arm64 or amd64.
  • The machine can download from GitHub over HTTPS. It needs curl or wget, sha256sum or shasum, and tar.
  • The agents you want to run are installed on the machine and signed in there.

Add a host

  1. Open Settings with ⌘, and select Hosts.
  2. Click Add host.
  3. Do one of these:
    • If the machine has an entry in your ~/.ssh/config, click its name under Suggested. Anywhere uses that entry's user, port, key, and jump host as they are.
    • Otherwise, fill in Address, Port, and Username.
  4. Choose how to sign in:
    • To use your SSH keys and ~/.ssh/config, change nothing.
    • To use a specific key, click Use a key file… and pick the file.
    • If the machine refuses your keys, type the Password.
  5. Click Connect.

Anywhere installs pocketd on the host and shows each step under Installing pocketd. When it finishes, the list says pocketd is installed, and the host's row says Connected with its version. If pocketd already runs on the host, Anywhere uses it.

Anywhere changes nothing in your ~/.ssh. If you sign in with a password, Anywhere uses it once to add a key for the app to the host's ~/.ssh/authorized_keys. It doesn't save the password.

What the install puts on the host

  • The pocketd release for the host's system, downloaded by the host from the Anywhere GitHub releases and checked against its SHA-256 sum.
  • The program at ~/.anywhere/bin/pocketd. A host set up by an older version keeps ~/.coding-pocket until its pocketd moves it.
  • A per-user service that starts pocketd: a LaunchAgent on macOS, a systemd user unit on Linux, or a Task Scheduler logon task on Windows.

NoteOn Linux, if lingering is off, pocketd stops when you log out of the host. Anywhere warns you and gives the command to turn it on, sudo loginctl enable-linger <user>.

Open a project on the host

  1. Press ⌘K and choose Open folder on a host….
  2. Pick the host and the folder.
  3. Click Add project.

The project shows in the sidebar with a globe icon and a dot for the connection. Start sessions in it as in any project. New worktrees of a host's project go in the host's ~/.anywhere/worktrees.

Keep a host up to date

When the host's pocketd is older than the app, its row in Settings › Hosts shows Update. Terminals on a Mac or Linux host stay open through the update.

WarningOn a Windows host, an update restarts pocketd, which closes that host's terminals. The update dialog says so before it runs.

Fix a host that doesn't connect

  • If the row says the host didn't accept your SSH keys, check that ssh to the host works in a terminal. Or click Use password to sign in once with a password.
  • If pocketd isn't running on the host, click Install.
  • To try the connection again, click Reconnect.

Remove a host

  1. In Settings › Hosts, click Remove on the host's row.
  2. Click Remove from this Mac, or Uninstall and remove to also uninstall pocketd from the host.

Removing a host disconnects it. Its projects leave your sidebar. The projects and files on the host stay.
