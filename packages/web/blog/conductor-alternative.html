Open-source Conductor alternative: Anywhere vs Conductor

By Minh Ngo · Published 18 November 2026 · Updated 18 November 2026

Anywhere is a free, MIT-licensed alternative to Conductor for running coding agents in parallel git worktrees with diff review. It supports ten agent CLIs, keeps local sessions running after you close the window, publishes Linux and Windows builds, and includes automations, a ticket Board and a CLI, with no paid tier.

DisclosureThe Anywhere team wrote this. Conductor facts come from conductor.build and its docs, checked on 18 November 2026. Both products ship often, so check the dates. If something here is out of date, open an issue.

Conductor in one paragraph

Conductor's own line is "Run parallel coding agents on your Mac." Its homepage goes on: "Create parallel Claude Code, Codex, and Cursor agents in isolated workspaces. See at a glance what they're working on, then review and merge their changes." Its docs put the split this way: "A harness is the agent runtime that writes code; Conductor is the workspace layer around it." It supports four harnesses, Claude Code, Codex, Cursor, and OpenCode, and ships Claude Code, Codex, and OpenCode bundled, so there is less to install. Each workspace has its own branch. Conductor says it is free to use and doesn't bill or resell model usage. Conductor Cloud runs workspaces in a sandbox under Pro, Teams, and Enterprise plans, and an iOS app shipped in version 0.90.0 on 2 October 2026. Review and merge is the core of the product, and it shows.

Anywhere in one paragraph

Anywhere is a desktop app for watching and driving many coding agents at once. The window is Rust on GPUI. A Go background service, pocketd, owns the terminals and sessions. It runs the agent CLIs you already installed and signed in to, puts each session under a project and a git worktree, tells you which one needs you, and keeps the diff and the pull request beside the session. The whole thing, desktop app, daemon, iPhone app, and push relay, is in one MIT-licensed repository.

Where Anywhere is different

Open source, MIT, no paid tier

Anywhere's site says it plainly: "There is no account to make, no seat to buy and no feature held back for a paid plan. There never will be." The pricing table lists the desktop app, the daemon and CLI, and the push relay at $0, and the cloud tier and premium tier as "Never". The architecture page adds that there is no license check in the code. You can read every line, build it yourself, and fork it.

Ten agent CLIs, including Grok Build, Pi, omp, fx, Hermes Agent, and Antigravity

Anywhere doesn't bundle agents. It runs the CLIs it finds on your login PATH, signed in to your own accounts, and never proxies a model or resells a token. That is one more install step than a bundle, and in return you choose the version, and you can use six agents beyond the four Conductor supports. Claude Code and Codex run in a real terminal or as a chat and report their status from both. The other eight run as a chat. The commands and sign-in steps are in Supported agents.

Local sessions that outlive the window

Conductor's Cloud FAQ is clear about its local workspaces: "Local workspace sessions run on your Mac. If you close the app or shut down your Mac, those sessions end." Its answer for long runs is Cloud. Anywhere's answer is a local daemon. pocketd runs every session and starts at login, so closing the window doesn't stop an agent, and on macOS the app itself stays in the background by default. See Sessions and status and Keep coding agents running after you close the window.

Linux and Windows builds, and SSH hosts

Anywhere publishes Linux and Windows archives next to the Mac app. To be straight about them: they are unsigned and have no updater, and you run pocket-desktop from the unpacked folder. You can also add a Mac, Linux, or Windows machine as a host over SSH. Anywhere installs pocketd there, and that host's projects show in your sidebar while their agents run on the host. See Run agents on another machine over SSH.

Automations, Board, and the anywhere CLI are included

  • Automations start a prompt on chosen weekdays at a time, or every few minutes, and keep firing while the desktop app is closed.
  • The Board holds tickets across projects. A started ticket gets its own worktree and session.
  • The anywhere command starts sessions, sends prompts, waits for results, and edits tickets from any shell.

When Conductor may fit better

Conductor is the better pick if you want

  • Claude Code, Codex, and OpenCode installed for you, as a bundle, instead of installing each CLI yourself.
  • A long-shipped, tightly scoped review and merge workflow on macOS, including workspaces from pull requests and stacks.
  • Cloud workspaces in a managed sandbox, the Conductor API, and shared workspaces.
  • An iOS app you can install today.
  • Team and Enterprise features such as multiplayer and an admin portal. Anywhere doesn't offer these and has said it won't sell a cloud tier.

Moving a workflow over

The model is the same: one isolated checkout and branch per task, an agent in it, review, merge. One Conductor workspace per task maps to one Anywhere worktree per task.

  1. Install and sign in to the CLIs you used through Conductor, for example claude auth login, codex login, opencode auth login, or cursor-agent login.
  2. Install Anywhere and add your repository as a project.
  3. Move workspace setup into .anywhere/config.json or .anywhere/setup.sh, so new worktrees install dependencies before the agent starts.
  4. Press ⌘⇧N to start a session in a new worktree, from a branch or from a pull request number.
  5. Review in Changes and merge from the pull request card.

FAQ

Is there an open-source alternative to Conductor?

Anywhere is a free, MIT-licensed alternative to Conductor for running coding agents in parallel git worktrees with diff review. It supports ten agent CLIs, keeps local sessions running after you close the window, publishes Linux and Windows builds, and includes automations, a ticket Board and a CLI, with no paid tier.

Does Anywhere work on Linux or Windows?

Yes. Anywhere publishes builds for Linux on x86_64 and Windows on x64. They are unsigned and have no updater, and the binary is pocket-desktop. The macOS app needs macOS 13 or later and is universal, signed and notarized. Conductor's desktop app is macOS only.

Which agents does Anywhere support compared with Conductor?

Anywhere runs ten agent CLIs that you install and sign in to yourself: Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, omp, fx, Hermes Agent and Antigravity. Conductor supports Claude Code, Codex, Cursor and OpenCode, and bundles Claude Code, Codex and OpenCode.

Do agents keep running if I close the app?

In Anywhere, yes. pocketd owns the terminals and sessions, so agents keep running after the window closes, and scheduled automations keep firing. Conductor's docs say local workspace sessions end if you close the app or shut down the Mac, and Conductor Cloud workspaces keep working instead.

Is Anywhere free?

Yes. Anywhere is MIT licensed and costs $0, with no account, no cloud tier and no premium tier. It runs the agent CLIs you already use and never proxies a model or resells a token.
