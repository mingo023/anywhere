A free, open-source agent workspace with no paid tier

By Minh Ngo · Published 18 November 2026 · Updated 18 November 2026

Anywhere is a free, MIT-licensed app for running coding agents in parallel that has no account, no cloud tier and no premium tier. Automations, a ticket Board, SSH hosts and the anywhere CLI are all included at no cost, and it runs the Claude Code, Codex and other agent CLIs you already use.

DisclosureThe Anywhere team wrote this. Prices come from each product's official pricing page, checked on 18 November 2026. Prices change; check the linked pages before you decide.

What "free" means across open-source agent workspaces

Credit where it's due. Paradev (formerly Superset; its CLI is still superset, and it is unrelated to Apache Superset) and Synara both keep their desktop apps MIT licensed and free, and both say so plainly. Paradev's README says the desktop app is free forever for running agents in parallel on your own machine. Synara's free plan says "No card, no account."

T3 Code is another free MIT app, and it goes further on price: its FAQ says "There's no way to pay us to use T3 Code. You bring your own sub." Like Anywhere, it runs the agent CLIs you already pay for, and you keep paying your provider.

Where Paradev and Synara differ from Anywhere is in what sits on top. Both sell hosted or remote features as paid plans, which is a reasonable way to fund a product. Here is what each one includes, from their own pricing pages:

What's included in Anywhere at $0

Everything in the app, with no plan, no seat, and no account:

  • Automations. A prompt pocketd starts on chosen weekdays at a time, or every few minutes. Runs keep firing while the desktop app is closed.
  • The Board. Tickets across projects. A started ticket gets its own worktree and session, with a limit on how many run at once.
  • SSH hosts. Add a Mac, Linux, or Windows machine. Anywhere installs pocketd there and runs that host's agents on it.
  • The anywhere command and agent skill. Start sessions, send prompts, wait for results, and manage tickets from any shell. The skill tells Claude Code and Codex how to use it.
  • Delegated work. A chat hands parts of its work to other sessions through pocketd's orchestrator over MCP.
  • A phone path, documented. A native SwiftUI iPhone and iPad app pairs with the Mac over Tailscale, with code and agents staying on the Mac. It is built and documented in Pair an iPhone; the site still lists it as coming soon. The one hosted piece is an optional push relay, which stores no device tokens.
  • Linux and Windows builds. Unsigned and without an updater, next to the signed, notarized Mac app.

Anywhere is MIT licensed, with no account and no paid tier.

No account, no cloud tier, no premium tier: the public promise

The Anywhere site puts it in writing: "There is no account to make, no seat to buy and no feature held back for a paid plan. There never will be."

Its pricing table lists the desktop app, the iPhone app, the daemon and CLI, and the push relay at $0, and two rows as "Never": cloud tier and premium tier. The architecture page backs that up with things you can check in the source:

  • All of it is in one MIT-licensed repository, and there is no license check in the code.
  • There is no Anywhere account and no Anywhere server your sessions pass through. "Your code, your terminals and your agents stay on your Mac or the hosts you add."
  • The one service the project runs is the push relay for iPhone notifications, and it stores no device tokens.
  • Anywhere's own code has no analytics, telemetry, or crash reporting.

T3 Code is close on price, and the honest difference is the promise. Its FAQ says this about T3 Connect: "We don't want to charge for this, but if the bill gets unacceptable we may have to change course. If you hit limits or have issues, you can always fork it, self host, or use Tailscale." That is a fair position for a hosted relay. Anywhere doesn't run a relay for remote sessions, and its site says there will never be a premium tier.

There is little to charge for, because there is little to host. That is a design choice, and it has costs: no cloud workspaces, no team seats, no hosted dashboard. If you need those, the two sections below are for you.

When Paradev may fit better

Paradev is the better pick if you want

  • Any CLI agent, with a long first-party list that includes Devin, Gemini CLI, GitHub Copilot, and Amp, which Anywhere doesn't list.
  • An in-app browser with Design mode, and Pages for sharing agent-made designs and reports.
  • Automations triggered by events from GitHub, Slack, Linear, Sentry, Notion, Microsoft Teams, or a webhook, not only a clock.
  • A TypeScript SDK and an MCP server.
  • An iPhone and iPad app on the App Store today, on Pro, with iOS 26 or later.
  • Team plans, cloud workspaces, and a SOC 2 Type II report.

When Synara may fit better

Synara is the better pick if you want

  • Browser verification, provider handoffs mid-task, and stacked pull requests, with a button that groups review comments into a fix.
  • Computer Use, the iOS Simulator, and Inbox and Kanban views.
  • Windows and Linux as first-class release targets, not unsigned side builds.
  • Devin CLI, Oh My Pi, or Factory Droid, which are on Synara's list and not on Anywhere's.
  • Remote and iPhone access today, as a clearly priced add-on.

T3 Code is the better pick if you want shipping iOS, Android, and web clients, first-class Windows and Linux builds, any ACP agent, or a built-in remote that doesn't need Tailscale. See Anywhere vs T3 Code.

FAQ

Is there a free alternative to Paradev Pro or Synara Alto?

Anywhere is a free, MIT-licensed app for running coding agents in parallel that has no account, no cloud tier and no premium tier. Automations, a ticket Board, SSH hosts and the anywhere CLI are all included at no cost, and it runs the Claude Code, Codex and other agent CLIs you already use.

Do I need an account to use Anywhere?

No. There is no Anywhere account for the desktop app, the daemon or the CLI, and the documented iPhone pairing goes over your own Tailscale network. You sign in only to the agent CLIs you use, with their own providers.

Will Anywhere ever add a paid plan?

The site says no: "There is no account to make, no seat to buy and no feature held back for a paid plan. There never will be." Its pricing table lists the cloud tier and the premium tier as Never, and the code is MIT licensed with no license check.

Does Anywhere charge for model usage?

No. Anywhere runs the agent CLIs you already installed and signed in to, and never proxies a model or resells a token. Model usage is billed by your agent's provider, under your own subscription or API key.
