Anywhere vs Paseo: a Paseo alternative for running coding agents

Last checked: November 2026. Paseo facts come from paseo.sh and the getpaseo/paseo README. Something out of date? Open an issue.

Paseo describes itself as an open source agentic development environment for desktop, mobile, web and CLI. Its desktop app starts a local daemon, and every client connects to it: directly, over SSH, or through an optional end-to-end encrypted relay that needs no account. Agents run in parallel, each in its own worktree, with an editor, terminals, diffs, pull requests and a browser in one window. The mobile app is native on iOS and Android.

Anywhere, the open-source coding agent workspace, is a native macOS app with a Linux build. It runs ten agent CLIs side by side, groups sessions by project and git worktree, tells you which one needs you, and keeps the diff and the pull request beside the session. It is MIT licensed, with no account and no paid tier.

The main difference

Both apps separate the agents from the window. A background process owns the sessions, so closing the app doesn't stop them. They differ in what connects to that process.

Paseo puts many clients on one daemon: desktop, web, iOS, Android, a CLI and a TypeScript SDK. The daemon can run on a laptop, a VM, a home server or in Docker. Its main interface is the agent chat.

Anywhere has one desktop client, and it reaches other machines over SSH. It treats the terminal as a first-class place to run an agent, and it is built around status: which session is working, which needs you, which is done.

Architecture and remote machines

Paseo's daemon runs wherever you install it, and clients reach it directly, over SSH, over Tailscale, or through its relay.

Anywhere's remote path is SSH. Add a Mac, Linux or Windows machine as a host and Anywhere installs its background service there for you, with your keys and ~/.ssh/config. The host's projects show in your sidebar next to local ones, and you can hand a session to a connected host, code and conversation included.

Mobile and web

Paseo is ahead here. Its iOS and Android apps are on the App Store and Google Play, it has a web client, and its plugins show up on every client.

Anywhere has no web client. Its native iPhone and iPad app is coming soon: it pairs with your Mac over Tailscale, sends push notifications and shows Live Activities. See Pair an iPhone.

Chat and terminal

Paseo's main interface is the chat, with terminals in split panes beside it.

In Anywhere, a session runs as a chat or in a real terminal with the agent's own interface. Claude Code and Codex report their status from both, so a terminal session still shows Needs you or Done. Sessions sit in tabs and splits, grouped by project and worktree. The Needs you inbox, the Dock badge and notifications cover every project at once. See Sessions and status.

Agents

Paseo runs Claude Code, Codex, Copilot, OpenCode, Pi, Antigravity and Muse Code through structured harnesses, more than thirty others through an ACP catalog, and custom CLI agents.

Anywhere runs a fixed list of ten: Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, omp, fx, Hermes Agent and Antigravity. Both apps use the agent CLIs you already installed and signed in to.

Planning and automation

Paseo has schedules and heartbeats, a CLI, a TypeScript SDK, an MCP server, and skills that let agents hand work to each other.

Anywhere has automations that keep firing while the window is closed, a Board where starting a ticket creates a worktree and a session, and delegated work, where a chat hands tasks to other sessions and waits for the results. The anywhere command scripts it:

anywhere session create --new-worktree --provider codex --prompt "Fix the flaky login test"
anywhere session wait <id> && echo ready for review
anywhere ticket create --project app --start "Cache the avatar images"

When Paseo is the better pick

  • You want a phone app today, on iOS or Android, or a client in the browser.
  • You want the daemon on a server, a VM or in Docker, reachable through a relay.
  • You want plugins that show up on every client.
  • You need an agent outside Anywhere's ten, through ACP or a custom CLI.
  • You open pull requests on GitLab, Gitea, Forgejo or Codeberg.
  • You want a built-in browser with an element picker, voice dictation, or a TypeScript SDK.

Why people pick Anywhere

  • Real terminal sessions with live status for Claude Code and Codex.
  • One Needs you inbox, Dock badge and notifications across every project.
  • SSH hosts that Anywhere sets up itself, with session handoff.
  • A Board, automations and delegated work in the same app.
  • MIT license, no account, no paid tier.

FAQ

Is Anywhere a free Paseo alternative?

Yes. Anywhere is a free, MIT-licensed coding agent workspace with no account and no paid tier. Paseo is also open source and needs no account, so the choice comes down to clients and workflow: Paseo has desktop, web, mobile and CLI clients, and Anywhere is a desktop app with SSH hosts, terminal sessions with status, and a Board.

Does Anywhere run on Windows?

Not as a desktop app yet. The Anywhere desktop app runs on macOS 13 or later and on Linux x86_64. You can connect a Windows machine as a host over SSH, and its projects and sessions show in the same sidebar.

Can I use my Claude Code subscription with Anywhere?

Yes. Anywhere runs the Claude Code CLI you already installed and signed in to, so your existing plan or API key does the work. Anywhere doesn't proxy models or resell tokens, and the same goes for the other nine agents it supports.

Does Anywhere have a phone app like Paseo?

Not yet. Anywhere's native iPhone and iPad app is coming soon. It pairs with your Mac over Tailscale, with push notifications and Live Activities. Paseo's iOS and Android apps are available now.

Do Anywhere sessions keep running when I close the window?

Yes. A background service owns the terminals, so sessions keep running after you close the window, and automations keep firing on schedule.
