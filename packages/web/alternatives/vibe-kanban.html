Anywhere vs Vibe Kanban: a Vibe Kanban alternative for coding agents

Last checked: November 2026. Vibe Kanban facts come from the Vibe Kanban README, releases, docs and shutdown post. Something out of date? Open an issue.

Vibe Kanban plans, runs and reviews coding agent work from a kanban board in your browser. You start it with npx vibe-kanban. Each workspace gets its own git worktree and branch, and one workspace can hold several repositories. bloop, the company behind it, shut down in April 2026; the project lives on, open source under Apache-2.0 and community maintained, and its local workspaces keep working.

Anywhere, the open-source coding agent workspace, is a native desktop app for macOS with a Linux build. Its Board holds tickets across projects, and starting a ticket creates a git worktree and an agent session. It is MIT licensed, with no account and no paid tier.

The main difference

Both tools follow the same loop: write the work down, run an agent on it in isolation, review the diff.

Vibe Kanban is a local server with a web UI. It takes one command to start, and it has review tools Anywhere lacks, such as inline diff comments and a preview browser.

Anywhere is a desktop app. Its Board is one view next to sessions, review, automations and hosts, and each started ticket becomes an ordinary session you can open, answer and review.

The Board

In Anywhere, press N on the Board and type the work. The first line becomes the title and the whole text becomes the prompt. Chips set the project, the agent, the base branch, and optionally a priority and a label.

Start a ticket with its Start button, with ⌘↩ in the composer, or by dragging it to Working. It waits in Queued until a slot is free; Work on at once allows 4 by default, from 1 to 8. Then it follows its session through the columns: To do, Queued, Working, Needs you, Done, In review, Merged and Closed. A merged pull request closes the ticket.

Vibe Kanban's Get Started page says that without signing in, the kanban board, issues and team features are unavailable, so check how the release you run behaves if the board is the part you use.

Isolation and repositories

Both give each piece of work its own git worktree and branch. Vibe Kanban can put several repositories in one workspace. Anywhere keeps one project per ticket.

In Anywhere, setup commands in .anywhere/config.json or .anywhere/setup.sh run in every new worktree before the agent starts. See Worktrees.

Review

Vibe Kanban shows diffs unified or side by side, collects inline comments and sends them to the agent, has a preview browser with devtools and device modes, and writes pull request descriptions.

Anywhere's Changes sits beside the session. It compares the worktree with its base branch as a pull request would, commits, pushes and opens the pull request. The pull request card shows checks, reviews and merge state, and its Send buttons hand a failed check or a GitHub review comment to the agent.

Install and interface

Vibe Kanban runs from one command and opens in the browser. Anywhere is an app you download: the Mac build is signed, notarized and updates itself, and a Linux build is published too. You install and sign in to each agent CLI yourself.

Anywhere's sessions keep running after you close the window, and its automations can add work on a schedule.

Tickets from the command line

The anywhere command adds, reads, edits and deletes Board tickets, so a script or another agent can fill the Board:

anywhere ticket create --project app --provider codex --base main --start "Fix the flaky login test"
anywhere ticket list
anywhere ticket update --prompt "Also cover the logout path" <id>

When Vibe Kanban is the better pick

  • You want one command, npx vibe-kanban, and a UI in the browser, with no app to install.
  • You want inline comments on diff lines, sent back to the agent.
  • You want a built-in preview browser with devtools and device modes.
  • You want workspaces that span several repositories.
  • You use agents Anywhere doesn't run, such as Gemini CLI, GitHub Copilot, Amp, Droid or Qwen Code.
  • Your setup already works. Its local workspaces still run.

Why people pick Anywhere

  • A native Board where each started ticket gets its own worktree and session.
  • A cap on how many tickets run at once, so the queue doesn't swamp your machine.
  • Review, pull request and merge beside the session that did the work.
  • Tickets from the command line, for scripts and other agents.
  • MIT license, no account, no paid tier.

FAQ

Is Anywhere a free Vibe Kanban alternative?

Yes. Anywhere is a free, MIT-licensed coding agent workspace with a Board where each started ticket gets its own git worktree and agent session. It has no web UI, inline diff comments or preview browser.

Is Vibe Kanban still maintained?

Yes, by its community. bloop, the company behind it, shut down on 10 April 2026 and said the project will live on, open source and community maintained. Its local workspaces keep working.

Does Anywhere have a kanban board for coding agents?

Yes. The Board holds tickets for every project. A started ticket waits in Queued until a slot is free, then gets its own worktree and session. It runs up to 4 tickets at once by default, adjustable from 1 to 8.

Does Anywhere run on Windows?

Not as a desktop app yet. The Anywhere desktop app runs on macOS 13 or later and on Linux x86_64. You can connect a Windows machine as a host over SSH, and its projects and sessions show in the same sidebar.

Can I use my Claude Code subscription with Anywhere?

Yes. Anywhere runs the Claude Code CLI you already installed and signed in to, so your existing plan or API key does the work. Anywhere doesn't proxy models or resell tokens, and the same goes for the other nine agents it supports.
