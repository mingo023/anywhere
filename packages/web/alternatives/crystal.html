Anywhere vs Crystal: a Crystal alternative for parallel Claude Code and Codex

Last checked: November 2026. Crystal facts come from the Crystal repository and README. Something out of date? Open an issue.

Crystal was an MIT-licensed app for running Claude Code and Codex sessions in parallel git worktrees. Its repository now opens with "Crystal Is Now Nimbalyst": Crystal was deprecated in February 2026 and replaced by Nimbalyst. The repository is still public and MIT licensed, so the code stays readable and forkable.

Anywhere, the open-source coding agent workspace, keeps Crystal's core idea: several Claude Code and Codex sessions at once, each in its own worktree. It is a native macOS app with a Linux build, MIT licensed, with no account and no paid tier, and it runs eight more agents besides those two.

The main difference

Crystal's authors point its users to Nimbalyst. This page doesn't compare Nimbalyst, because we haven't checked its features. It compares what Crystal did with what Anywhere does today.

Crystal centered on parallel sessions in worktrees. Anywhere does that, and adds what comes after: a status for every session, review beside it, and a pull request card.

A worktree per session

Press ⌘⇧N and the new session page opens with Worktree picked. Pick a branch, or enter a pull request number to start from that pull request. Anywhere shows each step: Fetching latest changes, Creating git worktree, Copying configuration, Setting up, Starting agent.

A new worktree has the committed files only, so setup commands install what the agent needs first. Commit them with the repository in .anywhere/config.json, or use .anywhere/setup.sh:

{
	"setup": ["pnpm install", "cp .env.example .env"]
}

Worktrees you made outside Anywhere can be imported from the project's menu. See Worktrees.

Claude Code and Codex side by side

Both run in a real terminal or as a chat, and both report their status from either. Eight more agents run as a chat: Cursor, Grok Build, OpenCode, Pi, omp, fx, Hermes Agent and Antigravity.

A chat can also delegate work: ask Claude Code to split a task, and it starts Codex sessions in their own worktrees, waits for them and reads their results.

Knowing which session finished

Every session is Working, Needs you, Done, Failed or Idle. The three that matter once you look away, Needs you, Failed and Done, reach the sidebar, the inbox, the Dock badge and notifications. Closing the window doesn't end a session.

Review, compare and clean up

Changes shows a session's diff beside it. The scope switch compares the worktree with its base branch, the way the pull request will show it. Commit, push and create the pull request from the commit box, then watch checks and merge from the pull request card.

When the work is merged, delete the worktree, and its branch if you want, from the sidebar. The longer guide for Crystal users is Crystal is now Nimbalyst.

Mapping a Crystal workflow

  • Start a session in its own worktree: ⌘⇧N, or the + on a project's row.
  • Run Claude Code and Codex together: pick the agent on the new session page; sessions sit under the project and worktree, in tabs and splits.
  • See which session finished: Done in the sidebar and the inbox, a notification, the Dock badge.
  • Compare a session's work with main: Changes, then the scope switch, then the base branch.
  • Commit and open a pull request: the commit box, then Commit, push and create PR.
  • Throw away a finished worktree: right-click it and choose Delete worktree.

When Crystal or Nimbalyst is the better pick

  • Your Crystal setup still does what you need. The code is public and MIT licensed, so you can keep running it or fork it.
  • You want the successor Crystal's authors chose. That is Nimbalyst; start from the Crystal repository.
  • You would rather not learn a new window right now.

Why people pick Anywhere

  • The same worktree-per-session model, now with ten agents.
  • A status on every session, and an inbox for the ones that need you.
  • Review, compare and pull request beside the session.
  • Setup commands that run in every new worktree.
  • MIT license, no account, no paid tier.

FAQ

Is Anywhere a free Crystal alternative?

Yes. Anywhere is MIT licensed and free, with no account and no paid tier. It runs Claude Code, Codex and eight more agents, each session in its own git worktree, with status and diff review.

What replaced Crystal?

Nimbalyst. Crystal's README says Crystal is deprecated and replaced by Nimbalyst, and gives February 2026 as the deprecation date.

Can I run Claude Code and Codex side by side like in Crystal?

Yes. In Anywhere, start each agent in its own worktree of the same project. Claude Code and Codex both run in a real terminal or as a chat, and both report Working, Needs you, Done, Failed or Idle from either.

Can I bring my Crystal worktrees into Anywhere?

Yes. Crystal kept each session in a git worktree. If git has worktrees of a project that Anywhere's sidebar doesn't list, the project's menu offers to import them, and they appear in the sidebar.

Can I use my Claude Code and Codex subscriptions with Anywhere?

Yes, for both agents Crystal ran. Anywhere starts the claude and codex CLIs you signed in to, so your own plans or API keys pay. Settings › Accounts can hold more than one account for each and shows their usage.
