# Anywhere

Watch and drive many coding agents (Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, and more) in one app. Runs on macOS and Linux, with an iPhone app to answer agents away from your desk.

## Features

- Sessions grouped by project and git worktree.
- A "needs you" inbox and notifications show which session is waiting on you.
- Review diffs next to the session that made the change.
- Create a worktree from a branch or a pull request and start an agent in it.
- Sessions keep running after you close the window.
- Connect another Mac, Linux, or Windows machine; its projects and sessions show up in the same sidebar. See [hosts docs](https://getanywhere.dev/docs/hosts).
- The `anywhere` CLI starts sessions, sends prompts and manages work from a shell. See [CLI docs](https://getanywhere.dev/docs/cli).
- Answer agents from your iPhone. See [iPhone docs](https://getanywhere.dev/docs/iphone) for pairing.

Supported agents and how to install them: [getanywhere.dev/docs/agents](https://getanywhere.dev/docs/agents).

## Install

**macOS** (13 or later): download [Zoes.dmg](https://github.com/mingo023/anywhere/releases/latest/download/Zoes.dmg) and drag Anywhere to Applications.

**Linux** (x86_64): download [Zoes-linux-amd64.tar.gz](https://github.com/mingo023/anywhere/releases/latest/download/Zoes-linux-amd64.tar.gz).

See the [install docs](https://getanywhere.dev/docs/install) to unpack the Linux archive and to install the `anywhere` command.
